## 6. Newly Discovered Defects and Resolutions During Verification

| Defect Discovered | Root Cause | Impact | Resolution |
| :--- | :--- | :--- | :--- |
| **Silent Site Expansion** | In `migration.ts`, `Math.max(declaredWFt, maxExtentXFt)` expanded declared site dimensions if a room was placed/moved outside bounds. | Weakened plot boundaries by expanding site to fit invalid geometry. | Fixed `migration.ts`: If explicit plot dimensions exist in `raw.plot_width` / `raw.plotWidth` / `raw.floors[0].plot_width` / `raw.form.width`, they are treated as authoritative and never overridden by room extents. |
| **AABB Bypass in Plot Containment** | `validatePlotContainment` checked `inAABB` and skipped polygon ray-casting if inside bounding box. | Non-rectangular or cut plots failed to detect out-of-bounds nodes in cut corners. | Removed AABB bypass: All nodes are validated against `doc.site.plotPolygon` using ray-casting with 0.25m tolerance. |
| **Missing Validation in `createUpdateRoomBoundsCommand`** | `createUpdateRoomBoundsCommand` lacked a `validate` function, allowing invalid dimensions (< 2.5 ft) to commit if validators only emitted warnings. | Users could resize rooms below minimum habitable dimensions. | Added dedicated `validate` method enforcing `newBoundsFt.width >= 2.5 && newBoundsFt.height >= 2.5` with severity `'error'`. |
| **Excessive Furniture Tolerance** | `validateFurnitureCommand` used a 0.5m (1.64 ft) tolerance. | Furniture could protrude significantly outside the site boundary. | Tightened tolerance to 0.30m (standard 12-inch exterior wall envelope and float precision) and added 4-corner rotated polygon ray-casting. |
